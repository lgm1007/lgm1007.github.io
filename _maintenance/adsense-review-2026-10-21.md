# 애드센스 재심사 전 수정 기록 — 2026-10-21

스크린샷에서 소유권 확인은 통과했고, 거절 항목은 **가치가 별로 없는 콘텐츠**였다. 광고 계정 설정을 맞추는 것만으로 해결되는 항목이 아니므로 콘텐츠와 탐색 경험을 함께 개선했다. Google이 문제 삼은 개별 URL은 공개되지 않아 아래 결함이 각각 직접 거절 원인이었다고 단정하지 않는다.

## 공식 기준과 확인된 문제

- [Google의 콘텐츠·사용자 환경 안내](https://support.google.com/adsense/answer/10015918?hl=ko)는 고유한 가치, 중복 콘텐츠 검토, 쉽게 탐색할 수 있는 구조를 함께 요구한다.
- [복제 콘텐츠 정책](https://support.google.com/publisherpolicies/answer/11190248?hl=ko)은 외부 콘텐츠에 논평·선별·추가 가치를 제공할 것을 설명한다.
- 기존 OAuth2 글은 공식 튜토리얼 번역 중심이었다. 독서 노트 21개와 짧은 설명의 글들도 추가 편집이 필요한 후보이며, 길이만으로 정책 위반을 판단하지 않았다.
- 전체 목록의 빈 My Clients 영역, 잘못된 RSS 주소, 일반 페이지에서 실행되는 태그 스크립트, 모바일의 고정 폭과 긴 코드·표가 사용자 경험을 떨어뜨렸다.
- Disqus shortname `mr-brown`은 사용자 확인 결과 본인 계정이 아니었다. 댓글 연결을 해제했다.
- Search Console에서 보고된 404의 구체적인 URL은 아직 받지 못했다. 새 RSS를 생성했다고 해당 404 항목까지 해결됐다고 간주하지 않는다.

## 수정한 내용

1. OAuth2 글을 인증·인가·세션 구분과 오류 단계별 진단 중심으로 개편했다. 원문 튜토리얼과 개정 사실을 명시했고 기존 게시일·URL을 유지했다.
2. DB 락 글에서 FOR UPDATE의 배타락 설명과 MVCC 일반 조회를 정정하고, 두 연결로 재현하는 절차와 실제 확인 결과를 추가했다.
3. Spring Security 글을 인자 없는 설정 API의 deprecation과 Lambda DSL 전환으로 바로잡고, 보호 기능을 유지한 예제로 교체했다.
4. 처음 방문한 독자를 위한 기존 프로젝트 글 3개와 읽기 안내를 홈에 추가했다.
5. 전체 글을 14개 주제로 정리하고, JavaScript 없이 해당 주제의 글을 읽을 수 있는 정적 페이지를 추가했다. 기존 tag.html 쿼리 주소도 유지했다.
6. 사용하지 않던 jekyll-tagging 설정·의존성을 제거해 중복 태그 페이지 생성을 없앴다.
7. RSS 20개 항목, 메타·canonical 단일 출력, head 구조, 페이지별 태그 스크립트 로드, assets 수집 규칙을 수정했다.
8. 페이지 2 이후의 프로필 이미지 상대 경로를 고쳤다. 모바일에서 표·인라인 코드·긴 제목이 화면 폭을 늘리지 않도록 수정했다.
9. 타인 Disqus 연결을 끄고 문의·개인정보처리방침·이용약관의 댓글 관련 설명을 현재 상태에 맞췄다. 기존 게시글은 숨기거나 삭제하지 않았다.
